# 한능검 2급 Concept Matching Game

`한능검.md`를 source of truth로 삼아 만든 오프라인 우선 정적 매칭 트레이너입니다. 현재 247개의 직접 관계 pair(S 106, A 94, B 42, C 5)를 포함하며, 2급 벼락치기 기본 범위는 S/A 200쌍입니다.

## 실행

`index.html`을 브라우저로 직접 열면 됩니다. 외부 CDN이나 서버가 필요 없습니다.

정적 호스팅에 배포하면 서비스 워커가 앱 파일을 캐시하며, 지원 브라우저에서는 홈 화면에 설치할 수 있습니다. 모든 경로는 상대 경로이므로 GitHub Pages, Cloudflare Pages, Netlify, Vercel 등의 하위 경로에서도 동작합니다.

로컬에서 PWA 동작까지 확인하려면 정적 서버로 이 폴더를 제공해야 합니다. 서비스 워커는 보안상 `file://`에서는 등록되지 않지만 카드 학습, 매칭, 저장 기능은 그대로 동작합니다.

## 목표

일반 플래시카드나 객관식 문제은행이 아니라, 시험장에서 역사 단서 문장을 읽는 순간 직접 연결되는 핵심 개념이 떠오르도록 반복하는 association matching trainer입니다. 매칭 보드는 단어 두 개를 나란히 찾는 방식이 아니라 `핵심 개념 ↔ 정답어를 가린 역사 단서 문장`을 연결하며, 정답 뒤에는 전체 역사 문장을, 오답 뒤에는 두 카드의 올바른 연결을 바로 보여 줍니다.

직접 관계 247쌍과 별도로 시대 흐름을 배열하는 순서 세트 17개를 포함합니다. 카드 학습·매칭·분류 훈련은 모두 `pairs.js`의 같은 pair와 같은 역사 단서 문장을 사용합니다.

기본 S/A 200쌍은 시대 흐름에 따라 10개 학습 세트로 나뉩니다. 각 세트는 17~21쌍이며 카드 학습과 매칭 훈련에 공통 적용됩니다. 세트 선택을 사용하지 않을 때는 기존처럼 시대, 우선순위, 훈련 유형을 직접 조합할 수 있습니다.

시험 전략은 S/A 핵심 범위에서 확실하게 풀 35문제, 즉 70점 상당을 먼저 확보하는 것입니다. 남은 문항은 빈칸 없이 같은 번호로 일렬 마킹하되, 이 우연 점수는 합격 계산에 포함하지 않고 70점 위의 안전마진으로만 취급합니다.

## 모드

- 2급 벼락치기: S/A priority만 사용
- 왕-정책: 왕·정부·인물과 정책·업적 중심
- 단체-활동: 단체와 활동·관련 인물·전투 중심
- 혼동 훈련: 같은 시대의 비슷한 개념을 섞어 훈련
- 오답 지옥: 오답, 느린 기억, 낮은 mastery, S priority를 우선 반복
- 전체 보존: B/C까지 포함한 전체 pair 사용

학습 방식은 카드 학습, 1분 리필 매칭, 순서 배치, 1분 분류 훈련으로 나뉩니다. 카드 학습은 `개념 → 설명` 순서로 카드를 넘기며, 같은 `핵심 개념 ↔ 역사 단서` 관계가 매칭에서는 두 카드로, 분류에서는 역사 단서의 정답 선택 문제로 출제됩니다. 세 훈련의 정오답과 숙련도는 같은 pair ID 기록에 누적되어 약한 관계의 반복 확률을 함께 높입니다. 순서 배치는 69개 항목에 연도·왕·대표 변화 같은 시기 판단 단서를 제공합니다. 모든 훈련의 열기·뒤집기·이동·정답·오답·다음 동작에는 효과음 토글을 따르는 짧은 피드백 음이 적용됩니다. 시간제 훈련의 오답은 `-50점·-1초`이며, 3초 안에 정답을 이어 가면 2연속부터 단계별 콤보가 표시됩니다. 제한 시간이 끝나면 진행 중이던 마지막 정답을 2초간 확인한 뒤 결과 화면으로 이동합니다. 매칭·순서·분류 문제를 5초 동안 풀지 못하면 정답 전체를 노출하지 않는 단계형 힌트가 표시됩니다.

## Cloudflare Pages 배포

별도 빌드 과정이 없는 정적 앱이다. Cloudflare Pages의 Direct Upload에서는 이 저장소 폴더 자체를 업로드하면 된다. Git 연동을 사용할 때는 프레임워크 프리셋을 선택하지 않고, 빌드 명령은 비워 두며, 빌드 출력 디렉터리를 `.`으로 지정한다. 연표 바로가기는 Pages의 확장자 없는 경로인 `/timeline`을 사용하고 실제 정적 파일은 `timeline.html`로 유지한다.

`_headers`는 HTML과 서비스 워커의 오래된 캐시를 방지하고 정적 응답에 기본 보안 헤더를 적용한다. 배포 뒤에는 첫 화면, 새로고침, 오프라인 재접속, 기록 저장, JSON 내보내기를 확인한다.

홈의 `랭킹`에서 이 기기에 저장된 매칭·분류 기록을 각각 확인할 수 있습니다. 두 랭킹은 탭으로 분리되며 결과 화면과 동일한 순위 데이터를 사용합니다. 훈련·랭킹·연표 화면에서 브라우저나 휴대폰의 뒤로가기를 누르면 사이트를 이탈하지 않고 홈으로 이동합니다.

## 저장

개념 학습·매칭·분류의 공통 pair 기록은 `localStorage`의 `historyMatchingRecords.v2`, 선택한 학습 세트는 `historyMatchingCurriculumSet.v1`, 순서 학습 기록은 `historyOrderingRecords.v1`, 랭킹 기록은 `historyMatchingLeaderboard.v1`에 저장됩니다. 매칭과 분류 랭킹은 서로 분리되며 점수 내림차순, 동점이면 맞힌 개수 내림차순으로 정렬됩니다. 홈의 `기록 관리`에서 모든 학습 기록을 하나의 JSON 파일로 내보내거나 다시 가져올 수 있습니다.

랭킹 JSON의 한 기록은 다음 구조입니다.

```json
{
  "id": "1786119000000-a1b2c3",
  "score": 3200,
  "matched": 18,
  "playedAt": "2026-08-08T00:00:00.000Z"
}
```

각 pair는 다음 기록을 가집니다.

```json
{
  "attempts": 8,
  "correct": 6,
  "wrong": 2,
  "instant": 3,
  "sure": 2,
  "slow": 1,
  "weak": 0,
  "averageTime": 3.4,
  "mastery": 72,
  "lastSeen": "2026-08-07T00:00:00.000Z",
  "streak": 2
}
```

## 라운드 모호성 방지

한 개념이 여러 pair를 가질 수 있으므로 라운드 생성 시 `left`와 `right`의 정규화된 텍스트를 모두 `usedTerms`에 넣습니다. 이미 등장한 개념이 포함된 pair는 같은 라운드에 추가하지 않습니다. 정답 판정은 카드 텍스트가 아니라 `pairId`로 처리합니다.
